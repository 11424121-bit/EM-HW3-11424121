##  拉普拉斯轉換 - 第3題

### 題目
求解微分方程：
$$\frac{d^2x(t)}{dt^2} + 6\frac{dx(t)}{dt} + 8x(t) = 1$$

**初始條件為：**
$$x(0) = 1, \quad x'(0) = 0$$

---

### 解題步驟

#### 步驟一：拉普拉斯轉換與代入初始條件
將初始條件代入導數轉換公式：

$L[x''(t)] = s^2X(s) - s$

$L[6x'(t)] = 6sX(s) - 6$

$L[8x(t)] = 8X(s)$

$L[1] = \frac{1}{s}$

轉換後的總方程為：
$$(s^2X(s) - s) + (6sX(s) - 6) + 8X(s) = \frac{1}{s}$$

#### 步驟二：移項與通分整理
$$(s^2 + 6s + 8)X(s) - s - 6 = \frac{1}{s}$$
$$(s^2 + 6s + 8)X(s) = \frac{1}{s} + s + 6$$
$$(s^2 + 6s + 8)X(s) = \frac{s^2 + 6s + 1}{s}$$
$$X(s) = \frac{s^2 + 6s + 1}{s(s+2)(s+4)}$$

#### 步驟三：部分分式展開
設 $\frac{s^2 + 6s + 1}{s(s+2)(s+4)} = \frac{A}{s} + \frac{B}{s+2} + \frac{C}{s+4}$，利用留數法求係數：

求 A（令 s = 0）：
$$A = \frac{0^2 + 6(0) + 1}{(0+2)(0+4)} = \frac{1}{8}$$

求 B（令 s = -2）：
$$B = \frac{(-2)^2 + 6(-2) + 1}{-2(-2+4)} = \frac{7}{4}$$

求 C（令 s = -4）：
$$C = \frac{(-4)^2 + 6(-4) + 1}{-4(-4+2)} = -\frac{7}{8}$$

得到展開式：
$$X(s) = \frac{1/8}{s} + \frac{7/4}{s+2} - \frac{7/8}{s+4}$$

#### 步驟四：反拉普拉斯轉換
$$x(t) = \frac{1}{8}L^{-1}\left[\frac{1}{s}\right] + \frac{7}{4}L^{-1}\left[\frac{1}{s+2}\right] - \frac{7}{8}L^{-1}\left[\frac{1}{s+4}\right]$$
$$\mathbf{x(t) = \frac{1}{8} + \frac{7}{4}e^{-2t} - \frac{7}{8}e^{-4t}}$$

##  傅立葉級數 - 第8題

### 題目
令 $f(x) = x^2$ 且 $x \in [-\pi, \pi]$，求函數 $f(x)$ 之傅立葉級數。

---

### 解題步驟

#### 步驟一：函數性質分析與公式簡化
首先檢驗函數的奇偶性：
$$f(-x) = (-x)^2 = x^2 = f(x)$$

由於 $f(x)$ 為偶函數，在對稱區間 $[-\pi, \pi]$ 內：
$$\text{正弦項係數（奇函數積分）必為零：} b_n = 0$$

餘弦項與常數項係數可利用對稱性簡化，積分區間縮小至 $[0, \pi]$ 並乘以 2。

因此，傅立葉級數公式簡化為：
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos(nx)$$

#### 步驟二：計算常數項係數 $a_0$
$$a_0 = \frac{2}{\pi} \int_{0}^{\pi} x^2 \, dx$$
$$a_0 = \frac{2}{\pi} \left[ \frac{1}{3}x^3 \right]_{0}^{\pi} = \frac{2}{3}\pi^2$$

#### 步驟三：計算餘弦項係數 $a_n$ （使用速算表格法）
$$a_n = \frac{2}{\pi} \int_{0}^{\pi} x^2 \cos(nx) \, dx$$

此處使用分部積分表格法（DI Method）求解：

| 正負號 | 微分項 (D) | 積分項 (I) |
| :---: | :---: | :---: |
| $+$ | $x^2$ | $\cos(nx)$ |
| $-$ | $2x$ | $\frac{1}{n}\sin(nx)$ |
| $+$ | $2$ | $-\frac{1}{n^2}\cos(nx)$ |
| $-$ | $0$ | $-\frac{1}{n^3}\sin(nx)$ |

對角線相乘並加總，得到積分結果：
$$a_n = \frac{2}{\pi} \left[ x^2 \left(\frac{\sin(nx)}{n}\right) + \frac{2x\cos(nx)}{n^2} - \frac{2\sin(nx)}{n^3} \right]_{0}^{\pi}$$

將上限 $\pi$ 與下限 $0$ 代入。已知 $\sin(n\pi) = 0$ 且 $\sin(0) = 0$，故所有 $\sin$ 項皆消去：
$$a_n = \frac{2}{\pi} \left[ \frac{2\pi \cos(n\pi)}{n^2} \right]$$

代入 $\cos(n\pi) = (-1)^n$，消去 $\pi$ 整理得：
$$a_n = \frac{4(-1)^n}{n^2}$$

#### 步驟四：帶回公式得出最終傅立葉級數
將 $a_0 = \frac{2}{3}\pi^2$ 與 $a_n = \frac{4(-1)^n}{n^2}$ 代入標準式：
$$f(x) = \frac{\frac{2}{3}\pi^2}{2} + \sum_{n=1}^{\infty} \frac{4(-1)^n}{n^2} \cos(nx)$$

$$\mathbf{f(x) = \frac{\pi^2}{3} + \sum_{n=1}^{\infty} \frac{4(-1)^n}{n^2} \cos(nx)}$$
