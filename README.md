## 工程數學作業 - 拉普拉斯轉換第 (3) 題

### 題目
求解微分方程：
$$\frac{d^2x(t)}{dt^2} + 6\frac{dx(t)}{dt} + 8x(t) = 1$$
初始條件為：$x(0) = 1, x'(0) = 0$

---

### 解題步驟

#### 步驟一：拉普拉斯轉換與代入初始條件
將 $x(0) = 1, x'(0) = 0$ 代入公式：
* $L[x''(t)] = s^2X(s) - s$
* $L[6x'(t)] = 6sX(s) - 6$
* $L[8x(t)] = 8X(s)$
* $L[1] = \frac{1}{s}$

轉換後的方程為：
$$(s^2X(s) - s) + (6sX(s) - 6) + 8X(s) = \frac{1}{s}$$

#### 步驟二：移項與通分整理
$$(s^2 + 6s + 8)X(s) - s - 6 = \frac{1}{s}$$
$$(s^2 + 6s + 8)X(s) = \frac{1}{s} + s + 6$$
$$(s^2 + 6s + 8)X(s) = \frac{s^2 + 6s + 1}{s}$$
$$X(s) = \frac{s^2 + 6s + 1}{s(s+2)(s+4)}$$

#### 步驟三：部分分式展開
設 $\frac{s^2 + 6s + 1}{s(s+2)(s+4)} = \frac{A}{s} + \frac{B}{s+2} + \frac{C}{s+4}$，利用留數法求係數：

* **求 $A$**（令 $s = 0$）：
  $$A = \frac{0^2 + 6(0) + 1}{(0+2)(0+4)} = \frac{1}{8}$$
* **求 $B$**（令 $s = -2$）：
  $$B = \frac{(-2)^2 + 6(-2) + 1}{-2(-2+4)} = \frac{-7}{-4} = \frac{7}{4}$$
* **求 $C$**（令 $s = -4$）：
  $$C = \frac{(-4)^2 + 6(-4) + 1}{-4(-4+2)} = \frac{-7}{8} = -\frac{7}{8}$$

得到：
$$X(s) = \frac{1/8}{s} + \frac{7/4}{s+2} - \frac{7/8}{s+4}$$

#### 步驟四：反拉普拉斯轉換
$$x(t) = \frac{1}{8}L^{-1}\left[\frac{1}{s}\right] + \frac{7}{4}L^{-1}\left[\frac{1}{s+2}\right] - \frac{7}{8}L^{-1}\left[\frac{1}{s+4}\right]$$
$$x(t) = \frac{1}{8} + \frac{7}{4}e^{-2t} - \frac{7}{8}e^{-4t}$$
